---
title: "Supported models on Ascend NPU hardware"
description: "Complete model support matrix for vLLM Ascend, covering text-only, multimodal, and embedding models across Ascend A2 and A3 hardware."
---

vLLM Ascend supports a broad range of large language models on Huawei Ascend NPU hardware. The support matrix below reflects the current testing and validation status for each model. Model support is actively evolving — check [GitHub issue #1608](https://github.com/vllm-project/vllm-ascend/issues/1608) for the latest additions and status changes.

## Legend

| Symbol | Meaning |
|--------|---------|
| ✅ | Supported |
| 🔵 | Experimental (interfaces or behavior may change) |
| ❌ | Not supported |
| 🟡 | Not tested or unverified |

<Info>
All models in this matrix have been tested on Ascend **A2** and/or **A3** hardware unless stated otherwise. Check each model's row for its specific hardware requirements before deploying.
</Info>
