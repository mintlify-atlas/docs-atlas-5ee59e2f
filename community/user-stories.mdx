## Fine-tuning with LLaMA-Factory

[LLaMA-Factory](https://github.com/hiyouga/LlamaFactory) is an easy-to-use platform for training and fine-tuning large language models. It supports hundreds of pre-trained models without requiring any custom code.

**Challenge:** LLaMA-Factory previously used the Transformers backend to run inference on Ascend NPUs, but inference speed was insufficient for iterative fine-tuning workflows.

**Solution:** LLaMA-Factory integrated vLLM Ascend via [pull request #7739](https://github.com/hiyouga/LlamaFactory/pull/7739), enabling fast post-fine-tuning evaluation and inference on Ascend NPUs.

**Result:** Benchmark results show up to **2× faster inference** compared to the Transformers implementation.

See [LLaMA-Factory Ascend NPU Inference](https://llamafactory.readthedocs.io/en/latest/advanced/npu_inference.html) for setup instructions.

## Reinforcement learning with verl and TRL

### verl

[verl](https://github.com/verl-project/verl) is a flexible and production-ready RL training library for LLMs. It added vLLM Ascend support in [v0.4.0](https://github.com/verl-project/verl/releases/tag/v0.4.0), enabling RLHF and other RL workflows to run on Ascend NPUs.

See the [verl × Ascend quickstart](https://verl.readthedocs.io/en/latest/ascend_tutorial/quick_start/ascend_quick_start.html) to get started.

### Hugging Face TRL

[TRL](https://github.com/huggingface/trl) is a cutting-edge library for post-training foundation models using SFT, PPO, and DPO. TRL uses vLLM Ascend since [v0.17.0](https://github.com/huggingface/trl/releases/tag/v0.17.0) to support RLHF on Ascend NPUs.

## Deployment with GPUStack

[GPUStack](https://github.com/gpustack/gpustack) is an open-source cluster manager for running AI models at scale. It added vLLM Ascend support in [v0.6.2](https://github.com/gpustack/gpustack/releases/tag/v0.6.2), enabling managed deployment of LLMs on Ascend hardware.

See the [GPUStack performance evaluation](https://mp.weixin.qq.com/s/pkytJVjcH9_OnffnsFGaew) for benchmark results on Ascend NPUs.

## Inference acceleration with MindIE Turbo

[MindIE Turbo](https://pypi.org/project/mindie-turbo) is an LLM inference engine acceleration plugin developed by Huawei for Ascend hardware. It includes self-developed LLM optimization algorithms and inference engine framework optimizations. MindIE Turbo has supported vLLM Ascend since [2.0rc1](https://www.hiascend.com/document/detail/zh/mindie/20RC1/AcceleratePlugin/turbodev/mindie-turbo-0001.html).

## Use cases covered

vLLM Ascend supports a broad range of real-world workloads on Ascend NPUs:

- **Fine-tuning workflows** — post-fine-tuning inference and evaluation with LLaMA-Factory
- **Evaluation** — fast batch inference for model benchmarking
- **Reinforcement learning** — RLHF and RL training loops with verl and TRL
- **Production deployment** — managed cluster serving with GPUStack
