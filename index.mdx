vLLM Ascend Plugin (`vllm-ascend`) is a community-maintained hardware plugin that enables running [vLLM](https://github.com/vllm-project/vllm) seamlessly on Huawei Ascend NPUs. It implements the [hardware-pluggable interface](https://github.com/vllm-project/vllm/issues/11162) so that popular open-source models — including Transformer, MoE, Embedding, and Multi-modal LLMs — run on Atlas A2 and A3 series hardware without modifying vLLM itself.

## What vLLM Ascend supports

<CardGroup cols={3}>
  <Card title="Atlas A2 & A3 NPUs" icon="microchip">
    Supports Atlas 800I A2/A3 inference series and Atlas 800T A2/A3 training series hardware.
  </Card>
  <Card title="Expert Parallelism" icon="share-nodes">
    Large-scale EP for MoE models like DeepSeek V3 and Qwen3-MoE across multiple NPUs.
  </Card>
  <Card title="Quantization" icon="compress">
    W8A8, W4A8, and W4A4 quantization to reduce memory and improve throughput.
  </Card>
  <Card title="ACL Graph Mode" icon="diagram-project">

  </Card>
  <Card title="PD Disaggregation" icon="arrows-split-up-and-left">

## Getting started

<Steps>
  <Step title="Set up your environment">
    Pull the official Docker image for your hardware (Atlas A2 or A3) and OS (Ubuntu or openEuler).

    ```bash
    export IMAGE=quay.io/ascend/vllm-ascend:v0.13.0
    docker run --rm --name vllm-ascend --shm-size=1g \
      --device /dev/davinci0 --device /dev/davinci_manager \
      --device /dev/devmm_svm --device /dev/hisi_hdc \
      -v /usr/local/dcmi:/usr/local/dcmi \
      -v /usr/local/bin/npu-smi:/usr/local/bin/npu-smi \
      -v /usr/local/Ascend/driver/lib64/:/usr/local/Ascend/driver/lib64/ \
      -v /root/.cache:/root/.cache \
      -p 8000:8000 -it $IMAGE bash
    ```
  </Step>
  <Step title="Run offline inference">
    Use the vLLM `LLM` class to run batched inference directly on the NPU.

    ```python
    from vllm import LLM, SamplingParams

    llm = LLM(model="Qwen/Qwen3-0.6B")
    sampling_params = SamplingParams(temperature=0.8, top_p=0.95)
    outputs = llm.generate(["The future of AI is"], sampling_params)
    print(outputs[0].outputs[0].text)
    ```
  </Step>
  <Step title="Or serve via OpenAI API">
    Start an OpenAI-compatible server and query it with any OpenAI client.

    ```bash
    vllm serve Qwen/Qwen3-0.6B
    ```

    ```bash
    curl http://localhost:8000/v1/completions \
      -H "Content-Type: application/json" \
      -d '{"model": "Qwen/Qwen3-0.6B", "prompt": "Beijing is a", "max_completion_tokens": 20}'
    ```
  </Step>
</Steps>

## Supported hardware

| Hardware Series | Status | Notes |
|---|---|---|
| Atlas A2 Training (800T A2, 900 A2 PoD) | Stable | Primary development target |
| Atlas 800I A2 Inference | Stable | Full feature support |
| Atlas A3 Training (800T A3, 900 A3 SuperPoD) | Stable | Larger EP configurations |
| Atlas 800I A3 Inference | Stable | High-throughput inference |
| Atlas 300I Duo | Experimental | Limited feature set |

<Note>
  vLLM Ascend Plugin requires CANN 8.5.1, PyTorch 2.9.0, and torch-npu 2.9.0. See the [installation guide](/installation) for the complete requirements list.
</Note>
